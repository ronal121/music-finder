# Music Finder — KAFSHAR

طراحی: **KAFSHAR**

نسخه اولیه با رابط تاریک، مینیمال و ظریف.

## منطق برنامه
1. کاربر عبارت آزاد فارسی یا انگلیسی وارد می‌کند.
2. برنامه Google را به‌عنوان لایه جستجو استفاده می‌کند.
3. جستجو عمداً منابع ایرانی و خارجی را محدود نمی‌کند.
4. نتیجه‌ها داخل WebView باز می‌شوند.
5. لینک‌های رسانه‌ای عمومی با MIME و context بررسی و برای پخش مستقیم به Media3 تحویل می‌شوند.
6. YouTube فقط به‌عنوان نتیجه خارجی نمایش داده می‌شود و منبع مستقیم MP3 نیست.

این پروژه برای دور زدن محدودیت دسترسی، DRM یا دانلود اجباری طراحی نشده است.

## ساخت APK
Android Studio → Open → پوشه پروژه → Gradle Sync → Build > Build APK(s)
