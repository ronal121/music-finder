# Music Finder — KAFSHAR

طراحی: **KAFSHAR**

نسخه اولیه با رابط تاریک، مینیمال و ظریف.

## منطق برنامه
1. کاربر عبارت آزاد فارسی یا انگلیسی وارد می‌کند.
2. برنامه Google را به‌عنوان لایه جستجو استفاده می‌کند.
3. جستجو عمداً منابع ایرانی و خارجی را محدود نمی‌کند.
4. نتیجه‌ها داخل WebView باز می‌شوند.
5. کاربر می‌تواند وارد سایت موسیقی شود و Play خود سایت را بزند.
6. در نسخه‌های بعدی می‌توان parserهای اختصاصی برای منابع مجاز اضافه کرد تا در صورت وجود لینک صوتی عمومی، پخش مستقیم هم ارائه شود.

این پروژه برای دور زدن محدودیت دسترسی، DRM یا دانلود اجباری طراحی نشده است.

## ساخت APK
Android Studio → Open → پوشه پروژه → Gradle Sync → Build > Build APK(s)

## امضای پایدار برای آپدیت درون‌برنامه‌ای

نسخه‌های منتشرشده برای نصب ارتقایی باید همگی با **یک کلید امضای ثابت** ساخته شوند. کلید خصوصی را داخل مخزن commit نکنید.

در GitHub repository، از مسیر **Settings → Secrets and variables → Actions** این چهار Repository Secret را تعریف کنید:

- `ANDROID_KEYSTORE_BASE64`: محتوای فایل keystore به صورت Base64 (مثلاً خروجی `base64 -w 0 release.jks`).
- `ANDROID_KEYSTORE_PASSWORD`: رمز keystore.
- `ANDROID_KEY_ALIAS`: alias کلید.
- `ANDROID_KEY_PASSWORD`: رمز کلید.

از همان keystore برای همهٔ نسخه‌های بعدی استفاده کنید و یک نسخهٔ پشتیبان امن و آفلاین نگه دارید. اگر keystore فعلی نسخهٔ نصب‌شده در دسترس است، همان را استفاده کنید. اگر نسخهٔ نصب‌شده با کلید Debug موقتی از runner ساخته شده باشد و کلیدش موجود نباشد، نمی‌توان بدون تطبیق امضا روی آن نصب ارتقایی انجام داد؛ ممکن است یک بار نصب مجدد لازم شود.

پس از تنظیم Secrets، اجرای موفق Full CI روی `main` یک APK امضاشده با نام `music-finder.apk` در release با برچسب `ci-latest` منتشر می‌کند. اگر Secrets تنظیم نشده باشند، CI همچنان APK آزمایشی Debug را به عنوان artifact ذخیره می‌کند، اما آن را برای آپدیت درون‌برنامه‌ای منتشر نمی‌کند.

## رفتار نصب اندروید

آپدیت درون‌برنامه‌ای فایل را دانلود می‌کند و نصب‌کنندهٔ رسمی اندروید را باز می‌کند. به‌دلایل امنیتی معمولاً باید کاربر نصب را تأیید کند؛ نصب کاملاً بی‌صدا و بازشدن اجباری برنامه پس از نصب در اپ عادی sideload شده تضمین‌پذیر نیست. اگر امضا و شناسهٔ بسته یکسان باشند و versionCode افزایش یافته باشد، اندروید می‌تواند نسخه را به‌صورت ارتقایی نصب کند و داده‌های برنامه را نگه دارد.
